# ACRUX 오프라인 Release Candidate 점검표

이 점검은 자동 하네스가 통과한 최종 후보의 `unpacked` 폴더만 사용한다. 빌드 폴더나 개발 PC의 파일을 대신 사용하지 않는다. 구현자가 아닌 검증자가 각 항목을 직접 확인하고, 실패한 후보는 수정하지 않은 채 실패 사유와 함께 구현자에게 돌려보낸다.

## 깨끗한 환경

- [ ] 별도 Windows 사용자 또는 깨끗한 Windows 10/11 VM을 사용했다.
- [ ] VC++ 재배포 패키지와 프로젝트 개발 도구에 의존하지 않는 환경이다.
- [ ] 네트워크 어댑터를 끄거나 연결을 제거한 뒤 실행했다.
- [ ] ZIP을 새 폴더에 직접 재해제했으며 다른 DLL이나 자산을 복사하지 않았다.
- [ ] 재해제 파일 목록이 `verification.json`과 일치한다.

## 실행과 입력

- [ ] `ACRUX.exe`가 누락 DLL·설치·권한 상승 요구 없이 시작한다.
- [ ] 방향키, Z, X, C, Esc만으로 시작 화면부터 플레이할 수 있다.
- [ ] HOW TO PLAY과 첫날의 짧은 안내만으로 활성 길의 안전·충전, Blink 비용, 제한 시간 내 귀환을 이해할 수 있다.
- [ ] 일시정지와 복귀 뒤 시간 또는 입력이 폭주하지 않는다.
- [ ] Alt+Tab으로 포커스를 잃으면 즉시 일시정지되고 복귀 뒤 시간 또는 입력이 폭주하지 않는다.
- [ ] 창을 960×540 클라이언트 영역보다 작게 줄일 수 없고, F11 전체화면 전환 전후에 화면 잘림과 보간 흐림이 없다.
- [ ] 오디오 장치가 없거나 사용할 수 없어도 게임이 종료되지 않는다.

## 필수 플레이 흐름

- [ ] 자원 획득, 자동 반납, 길 설치·철거·파손 수리와 활성 길 위 개인 Light 충전을 확인했다.
- [ ] Personal Light가 밤의 시간 경과만으로 줄지 않고 Blink·동물 접촉으로 줄며, 고갈 시 보유 자원만 잃는 것을 확인했다.
- [ ] Base Energy 고갈 실패와 다음 날 진행을 확인했다.
- [ ] 잠듦→태양 충전→황혼→다음 밤의 6초 전환(각 2초)이 서로 구분되고 파손 위치를 미리 노출하지 않는다.
- [ ] FOOD 0 위기 야간의 이동·운반 제한과 WATER 0 위기 야간의 시야·Blink 제한을 확인했다.
- [ ] 부족 자원 반납 시 위기가 즉시 해제되고, 해결하지 못한 채 다시 잠들거나 실패하면 게임 오버가 되는 것을 확인했다.
- [ ] MOTH 접촉, BOAR 접촉·돌진 피해가 빠른 이동 중에도 누락되지 않으며 동일 개체의 재피해 간격이 적용된다.
- [ ] BOAR 돌진이 활성 길 한 칸만 파손하고 기절하며, 수리 시 하류 전력과 폐회로 시야가 즉시 복구된다.
- [ ] RUSTLE과 SNARE는 밤마다 초기화되고 직접 피해 없이 각각 경계 유발과 일시 감속을 적용한다.
- [ ] 닫힌 활성 PATH 폐회로 내부가 희미하게 밝혀지고, 단절 즉시 꺼졌다가 복구되는 것을 확인했다.
- [ ] Blink 동안에만 가장 가까운 자원 신호가 나타나고 잔상 종료 뒤 사라지는 것을 확인했다.
- [ ] 세 릴레이 연결, 자발적 귀환·수면, 엔딩, 종료까지 완주했다.
- [ ] 마우스나 네트워크 없이 위 흐름을 모두 완료했다.

## 판정

- [ ] 자동 하네스와 이 점검이 모두 통과했다.
- [ ] 후보 SHA-256이 점검 시작 전후로 동일하다.
- [ ] 점검 중 후보 파일을 수정하지 않았다.
