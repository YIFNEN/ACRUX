# 자산과 공개 범위

## 기본 빌드

현재 이미지 데이터는 `src/generated/*.inc`에 포함되어 있습니다. 기본 빌드는 이 파일들을 사용하므로 이미지 편집 도구나 외부 자산 다운로드가 필요하지 않습니다. 생성된 파일을 직접 편집하지 않습니다.

## 포함한 파일

- `assets/source`: 원래 자산 기록에서 `project original`로 표기되어 있고 파일이 존재하는 원본을 선별했습니다.
- `assets/runtime`: 이미지 변환 후 실행 파일에 넣는 팔레트와 픽셀 데이터입니다.
- `assets/atlas.5bpp`: 변환된 아틀라스 데이터입니다.
- `docs/assets/asset-ledger.csv`: 이번 공개본에 포함한 원본의 기존 제작 기록을 유지했습니다. 생성형 AI, 사용자 제공 번들과 로컬 변환 과정을 구분합니다.

이 기록은 제작 경로를 설명합니다. 원본 폴더의 모든 시안이나 폐기한 실험을 공개한 것은 아닙니다. 포함된 파일이 모두 현재 화면에 표시되는 것도 아니며, 실제 빌드에서는 체크인한 생성 파일을 기준으로 합니다.

## 자산을 변경할 때

`embed-production-assets.ps1`, `embed-cutscene-assets.ps1`, `embed-title-assets.ps1`은 해당 runtime 데이터를 C++ include 파일로 변환합니다. `embed-assets.ps1`은 지정한 원본 시트로 아틀라스를 생성합니다. 변환 스크립트 실행은 기존 이미지 데이터를 바꾸는 작업이므로, 기본 빌드 과정에서는 실행하지 않습니다.

이미지 변경 시 관련 제작 기록과 실제 표시 결과를 함께 점검해야 합니다. 음악과 효과음은 소스에서 합성하며 외부 음원 파일을 배포하지 않습니다. 사용한 빌드 도구와 시스템 API는 [의존성 기록](release/dependency-ledger.csv)에 정리되어 있습니다.
